# Идеи новых фич для MultiRadio

## Общее описание
MultiRadio — многофункциональное интернет-радио без сборки и зависимостей. Ниже представлены идеи фич, которые:
- **Новые для радио** (ранее не встречались в подобных проектах)
- **Реалистичны** для реализации в чистом JavaScript с Web Audio API
- **Согласуются** с архитектурой проекта (стор, команды, события)

---

## 1. 🎯 **Лента воспроизведения (History Mode)**

### Описание
Записывает историю воспроизведения в реальном времени: какие станции играли, когда и как долго. Позволяет быстро вернуться к любимому эфиру или создать плейлист прошлого дня.

### Техническая реализация
- Новый state-фильд: `playbackHistory: [{ stationId, startTime, endTime, url }]`
- Триггер: при каждом `playback.status: 'playing'` записываем начало; при `idle` — сохраняем окончание
- Ограничение: хранить максимум 50 записей, старые удаляются FIFO
- UI: новая вкладка "История" с кнопкой "▶ Воспроизвести"
- Команда: `history:toggle` / `history:clear`

### Новизна
- Редко встречается в простых радиоплеерах
- Аналогично Spotify "Recently Played"

---

## 2. 🎵 **Автоматические сцены (Auto-Scenes)**

### Описание
Анализирует спектр и определяет "сцены" в музыке (бит, переходы, паузы). При смене сцены автоматически меняет визуализацию или подсвечивает станцию с пометкой "Энергетичный переход".

### Техническая реализация
- Использует существующий `analyser.js` для получения спектра
- Детектор басовых ударов через RMS и пиковые скачки (>40% изменение за 50мс)
- Новый state-филд: `currentScene: { type: 'beat' | 'silence' | 'transition', timestamp }`
- Событие: `scene:changed`
- Визуализация: мерцание границы плеера при бите, анимация при тишине

### Новизна
- Встроенный beat-detection без сторонних библиотек
- Автоматическое "резкое" переключение фоновой визуализации

---

## 3. 📊 **Аудиоанализ станций (Station Fingerprint)**

### Описание
Первый запуск станции или ручная проверка создаёт "отпечаток" звучания: средний битрейт, частотный спектр (басс/медиум/тредing), динамический диапазон. Позволяет оценить станцию по звуку, не слушая её полностью.

### Техническая реализация
- Новый сервис `analyser/station.js`: собирает 30-секундный сpectrum
- Сохраняет в state: `stationFingerprints: { [stationId]: { avgLevel, bassBoost, dynamicRange } }`
- Команда: `station:fingerprint` (в модалке станции)
- В UI: индикаторы рядом с именем станции (🎵, 🎤, 🎹)
- Экспорт/импорт включает fingerprint'и

### Новизна
- Анализ качества звучания без ручного прослушивания
- Аналогично Shazam, но для радио

---

## 4. 🕒 **Таймер воспроизведения (Sleep Timer)**

### Описание
Установите таймер, через который радио автоматически остановится. Полезно перед сном или работой.

### Техническая реализация
- Новый state-филд: `sleepTimer: { targetTime, remainingMs }`
- Команда: `sleep:start` (модалка с выбором: 30мин, 1ч, 2ч, произвольно)
- Команда: `sleep:cancel`
- Таймер реализуется через `setTimeout` в `audio.js::init()`
- В UI: кнопка в плеере с иконкой ⏰, индикатор обратного отсчёта

### Новизна
- Простая, но очень полезная фича для мобильных пользователей
- Аналогично iOS/Android sleep timer, но в браузере

## 5. 📱 **Режим "Карандаш" (Voice Search)**

### Описание
Голосовой поиск по станциям и эквалайзеру. Просто скажите: "Включи джаз", "Басс усилить", "Следующая станция".

### Техническая реализация
- API: Web Speech API (`speechRecognition`)
- Новые команды: `voice:start`, `voice:stop`
- Интерпретация речи через простые паттерны:
  - "включи/включай *жанр*" → фильтр по жанру + play
  - "басс/средние/высокие" → изменение EQ
  - "следующая/предыдущая" → next/prev
- Визуальный индикатор микрофона в шапке

### Новизна
- Голосовое управление в радиоплеере практически не встречается
- Аналогично голосовым помощникам, но локально

## 6. 🎛 **Экспресс-эквалайзер (Quick EQ)**

### Описание
Быстрые "стикеры" эффекта на полосах эквалайзера: "Кино", "Подкаст", "Рок", "Бас". Один клик — мгновенная настройка под жанр.

### Техническая реализация
- Расширенный `eqPresets` в `config/equalizer.js` с 10 базовыми пресетами
- UI: вкладка/кнопка в EQ показывает стилизованные кнопки
- Команда: `eq:preset` с выбором через модалку
- Автоматическое определение пресета по анализу спектра (опционально)

### Новизна
- Более детализированные пресеты с учётом жанра
- "Один клик" вместо ручной настройки полос

---

## 7. 🗺 **Карта станций (Station Map)**

### Описание
Визуализация станций по их географическому охвату. Интерактивная карта с маркерами, где клик по маркеру — воспроизведение станции.

### Техническая реализация
- Новые поля в станции: `country`, `city` (опционально)
- Используется тонкая лёгкая карта через Leaflet.js CDN (один файл) или Canvas
- Новый view: `stations:map`
- Команда: `view:map`
- Авто-определение страны по URL через IP-геолокацию (фасет в health-check)

### Новизна
- Геолокальная навигация по радио
- Интерактивный фон с маркерами вместо текстового списка

---

## 8. 🎧 **Сопровождение (Companion Mode)**

### Описание
Режим, при котором на второй вкладке/устройстве открывается управляющий интерфейс. Первое устройство — слушает, второе — добавляет станции, управляет EQ, делится в интернет.

### Техническая реализация
- Используется `BroadcastChannel` API
- Новый state-филд: `companionConnected: bool`
- Команды: `companion:start` (генерирует ссылку), `companion:connect` (подключается)
- UI: индикатор "👥 Присутствует опекун"

### Новизна
- Пара "радио + управление" на разных устройствах
- Аналогично Chromecast, но для радио

## 9. 📈 **Анализ потребления (Usage Stats)**

### Описание
Отслеживает, сколько времени вы потратили на каждую станцию и жанр. Еженедельный отчёт в виде простого графика.

### Техническая реализация
- Новый сервис `analytics.js`: фоновая статистика
- State: `usage: { [stationId]: { minutes: number, lastPlayed: ISODate } }`
- Команда: `stats:open`
- График через Canvas (простая лента времени)
- Экспорт в CSV/JSON

### Новизна
- Аналитика прослушиваний без сервера
- Мотивирует открывать новые станции

---

## 10. 🏆 **Система достижений (Achievements)**

### Описание
За прослушивание определённого количества станций, времени в одном жанре, использование всех эквалайзерных пресетов — выдаются достижения и появляется "коллекционирование".

### Техническая реализация
- Новые state-филды: `achievements: { [key]: { unlocked, count } }`
- Примеры: "100 часов прослушивания", "Пять жанров испытал", "Все пресеты EQ"
- UI: лёгкая анимация при разблокировке
- Команда: `achievements:open`

### Новизна
- Геймификация радио (редко встречается)
- Мотивирует исследовать коллекцию станций

---

## 11. 🔄 **Автосмена станций (Auto DJ)**

### Описание
Автоматически переключается между станциями согласно расписанию/жанру/метке. Например: "С 9 до 12 — новости, с 12 до 18 — музыка, вечером — классика".

### Техническая реализация
- Настройки: `{ stationId, timeRange, tags[] }` в конфиге станции
- Новый сервис `scheduler.js`
- Используется `MR.health` для проверки доступности перед переключением
- Команда: `autodj:enable/disable`

### Новизна
- Расписание для радио без ручного управления
- Аналогично smart playlists в Spotify

---

## 12. 📦 **Фоновый режим (Background Mode)**

### Описание
При сворачивании вкладки музыка продолжает играть, а UI сворачивается до минимального индикатора в системе треery.

### Техническая реализация
- Используется `Page Visibility API` и `AudioContext`
- При `document.hidden` — сворачиваем UI, сохраняем состояние
- Индикатор в виде звуковой волны в трее (через Notification API)
- Команда: `mode:background`

### Новизна
- Настольное поведение мобильного приложения
- Редко встречается в брачных радиоплеерах

## Приоритеты для реализации

### Критически важные (могут добавиться сейчас):
1. **Таймер воспроизведения** — простая и полезная фича
2. **Лента воспроизведения** — добавляет новый view без изменений в core
3. **Экспресс-эквалайзер** — расширение существующей функциональности

### Среднесрочные (требуют рефакторинга):
4. **Автосмена станций** — нужен планировщик
5. **Аудиоанализ станций** — расширение анализатора
6. **Голосовой поиск** — требует поддержки API браузера

### Долгосрочные (требуют архитектурных изменений):
7. **Карта станций** — нужен geocoding
8. **Companion Mode** — меж-вкладочная связь
9. **Система достижений** — новая логика
10. **Фоновый режим** — поведение при сворачивании

## Технические ограничения проекта

| Ограничение | Влияние на фичи |
|-------------|-----------------|
| Нет ES-модулей | Все код должен быть в IIFE |
| localStorage | Фичи не должны требовать сервер |
| Web Audio | Анализ спектра уже есть, можно расширить |
| Canvas | Визуализация через 2D API |
| Без сборки | Нужно добавить скрипты в правильном порядке |
| Один AudioContext | Нельзя создавать дополнительные контексты |
